# 🏀 Basketball Scoreboard

A clean, modern web application for tracking basketball game scores between **HOME** and **GUEST** teams.

## 🚀 Features

- **Interactive Score Counters:** Dedicated scoring controls for Home and Guest teams.
- **Flexible Increments:** Add points easily with `+1`, `+2`, and `+3` buttons.
- **Individual Reset:** Reset scores independently for each team.
- **Responsive & Dark UI:** High-contrast dark scoreboard theme built with custom CSS.

## 🛠️ Built With

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styling, Flexbox positioning, and clean interactive states.
- **JavaScript (ES6):** DOM manipulation for real-time score updates.
